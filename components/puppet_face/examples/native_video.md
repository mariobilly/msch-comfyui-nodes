# Native Video

Overlay landmarks and a cursor on inputs/demo.mp4 using native video loading and encoding. Precise tracking needs separately supplied models; the geometric test face demonstrates graphic overlay/fallback behavior, not a benchmark of facial landmark accuracy.

Load `native_video.json` on the ComfyUI canvas. `native_video_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
