# Opencv Video

All three PuppetFace nodes in one workflow. Select inputs/demo.mp4 in Load Video. The OpenCV loader/saver outputs a silent MP4 and does not preserve audio.

Load `opencv_video.json` on the ComfyUI canvas. `opencv_video_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
