# Captions

A caption alternative using the same synthetic beat track. Result captions.mp4 demonstrates fallback timing; use a suitable installed font for Arabic.

Load `captions.json` on the ComfyUI canvas. `captions_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
