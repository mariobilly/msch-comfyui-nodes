# Demo

Video batch processing using only this package and native ComfyUI video nodes. Uses inputs/demo.mp4. The demo clip is silent; an input clip with audio retains it through the separate audio connection. Results/demo.mp4 was rendered with these main effect settings.

Load `demo.json` on the ComfyUI canvas. `demo_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
