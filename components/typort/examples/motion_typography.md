# Motion Typography

A self-contained two-second typography export matching the gallery settings. Requires Playwright Chromium installed with ComfyUI Python. No input media, model, API key or additional custom node is needed.

Load `motion_typography.json` on the ComfyUI canvas. `motion_typography_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
