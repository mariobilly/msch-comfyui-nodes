# Single Photo

The renderer exports directly to ComfyUI/output/marioslideshow. Uses inputs/demo.png. For multiple photos, use the existing high_energy or modular workflows and select your own photo folder. The gallery demo was rendered from three original geometric frames.

Load `single_photo.json` on the ComfyUI canvas. `single_photo_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
