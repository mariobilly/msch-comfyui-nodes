# Photo Animation

Animate inputs/demo.png and save a native VIDEO. Includes only this package and standard ComfyUI nodes. The gallery render exercises a moving image batch; this workflow demonstrates animating one still with the same effect family.

Load `photo_animation.json` on the ComfyUI canvas. `photo_animation_api.json` is a prompt for the `/prompt` API, not a canvas workflow. Copy the required files from `inputs/` into `ComfyUI/input/` and reselect them in the load nodes.
