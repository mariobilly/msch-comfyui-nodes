# MSCH Scan FX

Stack up to eight thermal, night-vision, hologram, HUD, radar, glitch and other scan effects inside an optional mask.

This component is included in the **[MSCH Nodes pack](../../README.md)**. Install the pack once; no separate installation is needed.

[Full node reference](docs/NODES.md) · [Workflows and outputs](examples/README.md) · [Installation and optional dependencies](../../README.md#installation)

Effect slots run in order. White mask pixels receive the effect; mix and feather control compositing. Depth-map, thermal and X-ray looks are visual stylizations, not measured depth, temperature or internal anatomy. Animation advances across an IMAGE batch.
